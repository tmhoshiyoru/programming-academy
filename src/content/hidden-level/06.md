### 題目敘述

一個民俗舞蹈教學頻道有三部影片，分別教「閃身步」、「浪子踢球」和「狗熊哆嗦毛」。為了讓觀眾跟著練，頻道把三部影片放在三個視窗裡，從第 0 秒同時播放。每部影片播完就立刻從頭重播。

剪輯師想幫三部影片切成多個練習段落。每段要一樣長，每部影片都要剛好分完，而且每段越長越好。每段最長能有幾秒？這就是三部影片長度的最大公因數。

觀眾還想知道，錯過了第 0 秒的開場，最早要等到第幾秒，才會看到三個視窗再次同時從頭播放？這就是三部影片長度的最小公倍數。

給定三部影片的長度，請算出這兩個秒數。

### 輸入格式

輸入一行，包含三個以空白隔開的正整數，依序代表「閃身步」、「浪子踢球」和「狗熊哆嗦毛」的影片長度，單位為秒。

### 輸出格式

第一行輸出所有影片長度的最大公因數。

第二行輸出所有影片長度的最小公倍數。

### 範例輸入 1

```text
12 18 24
```

### 範例輸出 1

```text
6
72
```

### 範例輸入 2

```text
6 10 15
```

### 範例輸出 2

```text
1
30
```

### 解答

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;

    int x = a;
    int y = b;
    while (y != 0) {
        int r = x % y;
        x = y;
        y = r;
    }
    int gcd = x;
    int lcm = a / gcd * b;

    x = gcd;
    y = c;
    while (y != 0) {
        int r = x % y;
        x = y;
        y = r;
    }
    gcd = x;

    x = lcm;
    y = c;
    while (y != 0) {
        int r = x % y;
        x = y;
        y = r;
    }
    lcm = lcm / x * c;

    cout << gcd << endl;
    cout << lcm << endl;
    return 0;
}
```

### 解說

用 `cin >> a >> b >> c;` 一次讀入三部影片的長度。三個 `while` 都用同一個方法找兩個數的最大公因數。

先把要算的兩個數放進 `x` 和 `y`。每次用 `r = x % y` 算出餘數，再把 `y` 放進 `x`、把 `r` 放進 `y`。當 `y` 變成 0，`x` 就是這兩個數的最大公因數。

以第一組範例 `12 18 24` 為例：

1. 第一個迴圈算 12 和 18，得到最大公因數 6。用它算出前兩部影片的最小公倍數 `12 ÷ 6 × 18 = 36`。
2. 第二個迴圈算 6 和 24，得到三部影片的最大公因數 6。
3. 第三個迴圈算 36 和 24，得到公因數 12。用它算出三部影片的最小公倍數 `36 ÷ 12 × 24 = 72`。
