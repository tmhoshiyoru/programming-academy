---
title: 上機測驗考了 530 分的我正想去炫耀，才知道老師只給最高的三題雙倍配分
---

### 題目敘述

第一次上機測驗共有 7 題。考完後，有同學拿到每一題的分數，開心地加了起來。「我考了 530 分！」她說。旁邊的同學提醒她：「等一下，這場考試滿分只有 100 分。」

每一題的得分都是 0 到 100 分。計算總成績時，得分最高的 3 題各占 20%，其餘 4 題各占 10%。例如，一道占 20% 的題目拿了 80 分，就會替總成績加上 16 分。

老師已經把 7 個分數**由大到小排好了**。請依照上述配分，算出這次考試的總成績。

### 輸入格式

輸入一行，包含 7 個整數，每個整數都是 0 到 100 分，以空白隔開。分數已由大到小排列，可以有相同的分數。

輸入保證前 3 個分數都是 5 的倍數，後 4 個分數都是 10 的倍數，因此每題換算後的分數都是整數。

### 輸出格式

輸出一行，包含一個整數，表示加權後的總成績。

### 範例輸入 1

```text
100 90 80 80 70 60 50
```

### 範例輸出 1

```text
80
```

### 範例輸入 2

```text
100 95 90 80 80 70 60
```

### 範例輸出 2

```text
86
```

### 提示

範例1說明：

前 3 題各占 20%，合計得到 54 分。後 4 題各占 10%，合計得到 26 分。兩部分加起來是 80 分。

### 解答

```cpp
#include <iostream>
using namespace std;

int main() {
    int total = 0;

    for (int i = 1; i <= 7; i++) {
        int score;
        cin >> score;

        if (i <= 3) {
            total += score / 5;
        }
        else {
            total += score / 10;
        }
    }

    cout << total << endl;
    return 0;
}
```

### 解說

分數已經由大到小排好，讀到的前 3 個分數就是最高的 3 題。用 `i` 記住目前讀到第幾個分數，用 `total` 累加換算後的成績。

1. `i <= 3` 時，這題占 20%。20% 等於五分之一，所以用 `score / 5`。例如 80 分換算後是 16 分。
2. 從第 4 個分數開始，每題占 10%。10% 等於十分之一，所以用 `score / 10`。同樣是 80 分，在這裡換算後是 8 分。
3. 題目保證前 3 個分數能被 5 整除，後 4 個能被 10 整除，因此可以直接用整數除法。讀完 7 個分數後，輸出 `total`。
