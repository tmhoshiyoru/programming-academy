某天妳收到一封神秘的信，信中只寫了幾個詞：「綠市北一路123巷67號8樓」、「顧氏」、「三億」。在好奇心的驅使下，妳來到了信中的地址處，委託妳的人坐在辦公桌前一臉嚴肅的看著妳。在簡短的對話後，妳得知了幾個訊息：委託妳的人是北一城中權力最大的顧氏集團的公子——顧北辰，顧氏老爺——顧鈷谷打算將公司繼承給他的兒子，但掌權人只能有一個，於是顧鈷谷出了一個小朋友就會的題目給他的兩個兒子，在上千萬個數字中，誰最先找到那個嚴格過半的數字就能繼承公司。問題很簡單但太耗時了，顧北辰知道以這樣單純比速度，自己絕對贏不了弟弟——顧南辰，於是他找到了號稱全城最聰明的妳幫他解決這個問題。他還承諾如果他成功得到繼承權，將會給妳三億美金作為報酬！為了自己下半輩子的衣食無憂，請盡妳所能幫顧北辰搶到繼承權。

### 輸入格式

輸入 $k$ 個以空白隔開的正整數。讀到 $0$ 時停止，這個 $0$ 不計入 $k$。

### 輸出格式

輸出出現次數嚴格過半的正整數。也就是說，如果它出現了 $c$ 次，則 $2 \times c > k$。

### 資料範圍與限制

- 正整數的個數 $k$ 滿足 $1 \le k \le 10^{6}$。
- 每個正整數 $n$ 滿足 $1 \le n \le 10^{8}$。
- 輸入保證有一個正整數的出現次數嚴格過半。

### 提示

- 可以用`while (cin >> n)`逐一讀入數字，讀到 0 時結束迴圈。
- 數字可能很多。想一想，如果每次任取兩個不同的數字劃掉，出現次數嚴格過半的數字會不會被全部劃掉？

### 解答

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    int candidate = 0;
    int count = 0;

    while (cin >> n) {
        if (n == 0) {
            break;
        }

        if (count == 0) {
            candidate = n;
            count = 1;
        }
        else if (n == candidate) {
            count++;
        }
        else {
            count--;
        }
    }

    cout << candidate << endl;
    return 0;
}
```

### 解說

把每個數字想成一張寫著號碼的紙片。每次拿兩張號碼不同的紙片一起劃掉。假如有 5 張紙片，其中 3 張寫著 `3`，其餘只有 2 張。每劃掉一張 `3` 都要搭配一張其他號碼的紙片，所以即使兩張都用完，還是至少會剩下一張 `3`。

程式用 `candidate` 記住目前留下的是哪個數字，用 `count` 記住還留下幾個。每讀入一個數字，就照下面的方式處理。

1. 如果讀到 `0`，用 `break` 結束迴圈。
2. 如果 `count` 是 0，手上沒有紙片，就把新數字存進 `candidate`，並把 `count` 設成 1。
3. 如果新數字和 `candidate` 相同，就多留一張，讓 `count` 加 1。遇到不同的數字時，把新紙片和手上的其中一張一起劃掉，讓 `count` 減 1。

例如第二組範例 `3 3 1 0`，前兩個 `3` 讓 `count` 從 0 增加到 2。讀到 `1` 時劃掉一張 `3` 和一張 `1`，手上還留著一張 `3`。讀到 `0` 後輸出 `3`。題目保證有數字嚴格過半，因此最後留下的數字就是答案。
