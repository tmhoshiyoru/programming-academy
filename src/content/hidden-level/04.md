---
title: 每次下單都覺得這個價位很可以的韭留美，買完才想起來還沒算賺一倍和被抬出去的價格
---

### 題目敘述

韭留美用手上的錢買了好幾次同一種外國貨幣。每次看到價格，她都覺得「這個價位很可以」。買完一看，記帳本上已經多了好幾筆，她卻還沒算過自己總共花了多少。

每筆紀錄都寫著一單位要多少錢（單價），以及她買了幾單位（數量）。例如，單價是 10 元、買了 3 單位，這一筆就花了 30 元。把每筆花的錢加起來，就是她投入的本金。

如果她把手上的外幣一次賣光，能拿回的錢就是「賣出單價 × 總數量」。本題有兩種賣出的情況，計算時忽略手續費與利息。

- **賺到一個本金**：能拿回的錢剛好是本金的兩倍。扣掉原本花的錢，賺到的錢就剛好等於本金。
- **強制平倉**：能拿回的錢剛好只剩本金的一半。這時平台會自動把她手上的外幣全部賣掉。

給你韭留美的每筆買入紀錄，請算出在這兩種情況下，每一單位外幣的賣出價格。

### 輸入格式

第一行輸入一個整數 n，代表買入次數。

接下來有 n 行，每行輸入兩個整數 p 和 q，分別代表該筆買入的單價和數量，兩數以空白隔開。

### 輸出格式

第一行輸出獲利剛好等於本金時的單價。

第二行輸出外匯的總價值剛好降到本金一半時的強制平倉單價。

### 範例輸入 1

```text
2
10 3
18 1
```

### 範例輸出 1

```text
24
6
```

### 提示

範例說明：

韭留美共買了 4 單位，投入的總本金是 48 元。

1. 單價為 24 時，全部賣出可得 96 元，獲利 48 元，剛好等於本金。
2. 單價降到 6 時，全部賣出可得 24 元，是本金的一半，因此會觸發強制平倉。

### 評分方式

- 如果你幫韭留美算好兩筆買入的結果，可以獲得70分
- 如果你可以算到n最多100筆買入的結果，可以獲得滿分100分

### 解答

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int totalCost = 0;
    int totalQuantity = 0;

    for (int i = 0; i < n; i++) {
        int p, q;
        cin >> p >> q;

        totalCost += p * q;
        totalQuantity += q;
    }

    int averagePrice = totalCost / totalQuantity;
    int profitPrice = averagePrice * 2;
    int liquidationPrice = averagePrice / 2;

    cout << profitPrice << endl;
    cout << liquidationPrice << endl;
    return 0;
}
```

### 解說

先把每一筆買入的金額和數量分開累加。有了總本金和總數量，就能用「想拿回的錢 ÷ 總數量」算出每一單位要賣多少錢。

1. 每讀到一筆紀錄，就把 `p * q` 加到 `totalCost`，把 `q` 加到 `totalQuantity`。範例的本金是 `10 × 3 + 18 × 1 = 48` 元，總數量是 `3 + 1 = 4` 單位。
2. 要賺到一個本金，賣出後要拿回 `48 × 2 = 96` 元。把 96 元分到 4 單位，每單位要賣 `96 ÷ 4 = 24` 元。
3. 強制平倉時，賣出後只拿回 `48 ÷ 2 = 24` 元。把 24 元分到 4 單位，每單位是 `24 ÷ 4 = 6` 元。

程式先用本金除以總數量，算出平均買入單價。範例中是 `48 ÷ 4 = 12` 元，再乘以 2 得到 `24`，除以 2 得到 `6`。題目中這些運算都能整除，因此可以一路用 `int` 計算。
