title: 他叫我 101 欸，康永哥！我明明是塊 OREO，怎麼連白色夾心都被叫成了 0？
---

### 題目敘述

![康永哥-他叫我101欸.png](https://oj.fg.tp.edu.tw/public/upload/4f5b11acc5.png)

康永哥轉頭一看，坐在旁邊跟他說話的，竟然是一塊 OREO。

「叫你 101？他為什麼這樣叫你？」康永哥問。

「你先看這張圖。」OREO 說。

![OREO-原始梗圖.jpg](https://oj.fg.tp.edu.tw/public/upload/ecbff4f1b8.jpg)

梗圖把`OREO`拆成`O`、`RE`、`O`三塊。`O`是黑色餅乾，`RE`是白色夾心。多放幾層夾心，名字裡就多幾個`RE`。

「如果黑色餅乾是`1`，白色夾心是`0`，那我就是`1 0 1`啊。」OREO 說。

現在，康永哥拿到一串由`0`和`1`組成的數字。請照原本的順序，把每個`0`換成`RE`、每個`1`換成`O`，再把它們接起來，中間不加空白。

### 輸入格式

第一行輸入一個正整數 n，代表接下來有幾個數字。

第二行輸入 n 個數字，每個數字都是 0 或 1，以空白隔開。

### 輸出格式

輸出一行，依序印出每個數字對應的文字。遇到`0`就印出`RE`，遇到`1`就印出`O`，中間不加空白。

### 範例輸入 1

```text
3
1 0 1
```

### 範例輸出 1

```text
OREO
```

### 範例輸入 2

```text
4
0 0 1 1
```

### 範例輸出 2

```text
REREOO
```

### 提示

用 for 迴圈讀入 n 個數字。每讀到一個數字，就用 if 和 else 判斷要輸出哪一塊，最後再換行。

### 解答

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    for (int i = 0; i < n; i++) {
        int num;
        cin >> num;

        if (num == 0) {
            cout << "RE";
        }
        else {
            cout << "O";
        }
    }

    cout << endl;
    return 0;
}
```

### 解說

先用 `cin >> n;` 讀入數字的個數，再讓 `for` 迴圈執行 `n` 次。每次讀進一個數字，立刻輸出對應的文字。

1. `num == 0` 成立時，輸出 `RE`。題目保證每個數字都是 0 或 1，所以進到 `else` 時就是讀到了 1，輸出 `O`。
2. 迴圈裡的兩個 `cout` 都只輸出文字，前後也沒有加空白。以第一組範例來說，讀到 `1 0 1` 時，依序輸出的 `O`、`RE`、`O` 就會接成 `OREO`。
3. 所有數字都處理完後，再用 `cout << endl;` 換行。
