### 題目敘述

永二老是把愛子的名字叫成別人的名字，讓愛子（`AIKO`）很不開心。於是，她決定在心裡給永二打個分數。**一開始是 10 分**，每叫錯一次就扣 1 分。但永二每叫對一次愛子的名字，心中的分數會因為不小心大意而加 5 分。

請算出永二叫完所有名字時，愛子心裡的分數還剩下多少。

![第二題題目照片](https://oj.fg.tp.edu.tw/public/upload/4756961f47.jpg)

### 輸入格式

重複輸入名字，每個名字是一個字串，可以用 `string` 型態的變數儲存。使用 `while (cin >> s)` 讀取名字，讀到沒有更多字串時停止。輸入有可能會出現 `AIKO`，也可能完全沒有。

### 輸出格式

輸出一個整數，表示愛子心裡最後的分數。每叫錯一次扣 1 分，叫對時加 5 分。最後的分數可以是負數。

### 範例輸入 1

```text
YUKO
SAYOKO
RITSUKO
AIKO
```

### 範例輸出 1

```text
12
```

### 提示

可以用 `string s;` 儲存讀入的名字，並用 `s != "AIKO"` 判斷這次是否要扣分。

#### Hint:

> `==`、`!=`不是比較數字是否相等嗎？
>
> 沒有錯，但是**這裡已經變了**
>
> 對字串來說，這兩個符號也可以判斷前後字串是否相等

### 解答

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int score = 10;
    string s;

    while (cin >> s) {
        if (s != "AIKO") {
            score -= 1;
        }
        else {
            score += 5;
        }
    }

    cout << score << endl;
    return 0;
}
```

### 解說

用 `score` 記住目前的分數，一開始把它設成 10。每讀到一個名字，就立刻更新分數。

1. `while (cin >> s)` 每次把一個名字讀進 `s`。成功讀到名字就執行迴圈，讀完所有名字後就離開迴圈。
2. `s != "AIKO"` 成立時，代表這次叫錯名字，用 `score -= 1;` 扣 1 分。其餘情況就是叫對了，用 `score += 5;` 加 5 分。
3. 離開迴圈後，用 `cout` 輸出最後的分數。

以第一組範例來看，前三個名字都叫錯，分數依序從 10 降到 9、8、7。最後讀到 `AIKO`，加 5 分變成 12，所以輸出 12。
