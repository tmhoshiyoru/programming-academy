當程式需要多次執行相同的開關燈動作時，撰寫自訂函式（Function）可以大幅簡化程式碼並提高可讀性。
在此階段，我們將「亮燈時間」當作參數傳入函式中，打包重複的動作。

函式設計範例：自訂亮燈時間
```c=
#define LED_PIN 48

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

// 自訂控制函式：傳入亮燈時間（duration）與關燈時間（offDuration）
void lightUp(int duration, int offDuration) {
  digitalWrite(LED_PIN, HIGH); // 點亮
  delay(duration);             // 依參數決定亮燈時間
  digitalWrite(LED_PIN, LOW);  // 熄滅
  delay(offDuration);          // 依參數決定關燈時間
}

void loop() {
  lightUp(200, 200);  // 短亮：亮 0.2 秒、滅 0.2 秒
  lightUp(600, 200);  // 長亮：亮 0.6 秒、滅 0.2 秒
  
  delay(2000);        // 告一段落後等待 2 秒
}
```
