## 1. 圖例顏色與功能說明

開發板腳位具備多重功能（Multiplexing），以下為各代表顏色的功能分類：
* <span style="background-color: #E53935; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">PWD</span> **(紅色 / 電源)**：供電輸入或輸出（如 `3V3`, `5V`）。
* <span style="background-color: #333333; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">GND</span> **(黑色 / 地線)**：接地端。
* <span style="background-color: #1E88E5; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">Serial</span> **(藍色 / 序列埠)**：UART 序列通訊（如 TX/RX，常用於除錯與燒錄）。
* <span style="background-color: #4CAF50; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">ADCX_CH</span> **(綠色 / 類比轉數位通道)**：可讀取類比訊號（如可變電阻、光敏電阻）。
* <span style="background-color: #FBC02D; color: black; padding: 2px 6px; border-radius: 3px; font-weight: bold;">RESET</span> **(黃色 / 重置)**：晶片復位腳位 (`RST / EN`)。
* <span style="background-color: #FB8C00; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">GPIOX</span> **(橘色 / 通用輸入輸出)**：控制一般數位高/低電位的 GPIO 編號。
* <span style="background-color: #8E24AA; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">TOUCHX</span> **(紫色 / 觸控感測器)**：支援電容式觸控按鈕功能的通道。
* <span style="background-color: #FFB300; color: black; padding: 2px 6px; border-radius: 3px; font-weight: bold;">STRAP</span> **(淺橘色 / 啟動組態)**：Bootstrapping 引腳，決定晶片開機模式。
* <span style="background-color: #00ACC1; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">SD</span> **(青色 / SD 卡專用)**：板載 SD 卡槽使用的 SPI 通訊腳位。
* <span style="background-color: #03A9F4; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">LED</span> **(淺藍色 / 板載指示燈)**：板載指示燈（如 TX/RX 或 POWER/Status LED）。
* <span style="background-color: #D81B60; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">WS2812</span> **(桃紅色 / 全彩 LED)**：板載彩色 WS2812 RGB LED 燈腳位（GPIO48）。
* <span style="background-color: #C2185B; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">PSRAM</span> **(深桃紅 / 擴充記憶體)**：板載外接 PSRAM 晶片所使用的引腳（標有星號 `*`）。
* <span style="background-color: #C0CA33; color: black; padding: 2px 6px; border-radius: 3px; font-weight: bold;">USB</span> **(黃綠色 / 原生 USB)**：ESP32-S3 原生 USB 介面腳位（`USB_D-`, `USB_D+`）。
* <span style="background-color: #00897B; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">CAMERA</span> **(藍綠色 / 相機介面)**：專門連接 DVP 鏡頭（如 OV2640）的控制與數據傳輸腳位。
* <span style="background-color: #2E7D32; color: white; padding: 2px 6px; border-radius: 3px; font-weight: bold;">JTAG</span> **(深綠色 / 偵錯介面)**：用於硬體偵錯（Debug）的介面（MTMS, MTDI, MTDO, MTCK）。
* **`〰️` (波浪圖示)**：代表該腳位支援 **PWM（脈衝寬度調變）**，可用於控速、馬達、蜂鳴器調音、LED 調光等。

## 3. 開發注意事項

1. **帶有星號 `*` 的腳位 (GPIO 35, 36, 37)**：
   * 標示為桃紅色的 **PSRAM** 腳位被內部模組用來與記憶體通訊。如果程式開啟了 PSRAM 功能，**請勿外接任何元件到 GPIO 35, 36, 37 上**。
2. **GPIO 48 (WS2812)**：
   * 開發板上內建一顆 WS2812B 全彩 RGB LED 燈。若想控制板載彩色燈，直接對 GPIO 48 發送 WS2812 訊號即可。
3. **GPIO 0 (Boot 腳位)**：
   * 開機時若拉低（接地）會進入燒錄模式。平常作為通用輸入時，請勿在開機瞬間將其接地。
4. **Wi-Fi 與 ADC2 的衝突問題**：
   * 當 ESP32 開啟 **Wi-Fi** 功能時，**ADC2（如 GPIO 11~20）將無法準確讀取類比訊號**。讀取類比感測器請優先選用 **ADC1 通道**（GPIO 1~10）。
