### LCD1602 文字繪製與動態計數器
在 LCD1602 螢幕上繪製雙行文字，並即時更新 ESP32-S3 開機後經過的秒數：
- 第一行 (Row 0)：
  - 游標靠最左側對齊 (0, 0)。
  - 靜態顯示歡迎文字：Hello ESP32-S3!。
- 第二行 (Row 1)：
  - 游標靠最左側對齊 (0, 1)。
  - 顯示標籤 Uptime:  搭配開機總秒數（透過 millis() / 1000 計算）。
  - 單位顯示  s，且必須包含足夠的空格進行殘留字元清空（覆蓋），避免位數變更時畫面產生雜訊。
- 螢幕硬體控制：
  - 必須成功啟動背光，並透過背面的可調電阻調至清晰對比度。

### 💻 程式碼填空練習
請根據上述規格說明，完成以下程式碼填空：

```c=
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const uint8_t PIN_SDA = 8;
const uint8_t PIN_SCL = 9;

// 1. 填入實作一掃描到的位址 (如 0x27)，並設定 LCD 為 16 欄 2 列
LiquidCrystal_I2C lcd(0x____, 16, 2);

void setup() {
  // 強制綁定 ESP32-S3 的 I2C 腳位 (速度 100kHz)
  Wire.begin(PIN_SDA, PIN_SCL, 100000);

  // 2. 初始化 LCD 螢幕並開啟背光
  lcd.____();
  lcd.____________();
  lcd.clear();

  // 3. 將游標移動到 [第一行第 0 格] (Col 0, Row 0)，並印出 "Hello ESP32-S3!"
  lcd.setCursor(__, __);
  lcd.print("Hello ESP32-S3!");
}

void loop() {
  // 4. 計算系統開機後經過的秒數 (毫秒轉換為秒)
  unsigned long seconds = millis() / ______;

  // 5. 將游標移動到 [第二行第 0 格] (Col 0, Row 1)
  lcd.setCursor(__, __);
  
  // 6. 輸出計數文字與秒數，並補空白字元蓋掉殘留舊數字
  lcd.print("Uptime: ");
  lcd.print(seconds);
  lcd.print(" s   ");

  delay(500);
}
```
