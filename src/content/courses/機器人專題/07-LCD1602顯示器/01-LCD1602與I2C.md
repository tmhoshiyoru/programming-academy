一、 什麼是 LCD1602？
LCD1602 是一種常見的字元型液晶顯示器，共有 2 行（Row 0, Row 1），每行可顯示 16 個字元（Column 0 ~ 15）。

二、 傳統 LCD1602 的接線方式（平行傳輸）
傳統的 LCD1602 模組背面有 16 支引腳。若要讓它正常運作，微控制器需要透過平行傳輸（Parallel）方式同時連接多支數據線與控制線。為了改善接線繁雜的問題，工程師在 LCD1602 背面加裝了一塊 I2C 轉接晶片 (PCF8574)。

🌟 導入 I2C 的三個好處：
- 節省腳位：將原本需要 10+ 支的控制線，縮減為只需 2 支訊號線（SDA、SCL）。
- 電路簡化：加上 VCC 與 GND，只需要 4 條線即可運作。
- 支援多裝置串接：I2C 是匯流排（Bus）架構，多個感測器可以共用相同的 SDA 與 SCL 腳位，只要門牌號碼（I2C 位址）不同即可。

|LCD I2C 引腳|ESP32-S3 腳位|腳位類型|備註|
|:---:|:---:|:---:|:---:|
|VCC|5V (VIN)|電源正極|⚠️ 務必接 5V，接 3.3V 液晶顯色會太淡|
|GND|GND|電源接地||
|SDA|GPIO 8|I2C 數據 (Serial Data)|傳輸文字與指令|
|SCL|GPIO 9|I2C 時脈 (Serial Clock)|同步傳輸節奏|

#### 畫面無字除錯指引
若燒錄後螢幕僅亮背光但未出現文字，請使用小螺絲起子旋轉 LCD 背面的藍色可調電阻（電位器），調整螢幕對比度直到文字清晰。


### 找出你的I2C門牌號碼
每個 I2C 設備都有一個專屬的 16 進位位址（門牌號碼）。請透過以下程式碼，掃描你的 LCD 位址是 0x27 還是 0x3F：
大部分模組為 0x27，少數會是 0x3F。

```c=
#include <Wire.h>

// 1. 請填入 ESP32-S3 的預設 I2C 腳位
#define SDA_PIN 8
#define SCL_PIN 9

void setup() {
  Serial.begin(115200);
  
  // 2. 初始化 I2C 匯流排 (填入腳位變數)
  Wire.begin(SDA_PIN, SCL_PIN);
  
  Serial.println("\n--- 開始掃描 I2C 裝置 ---");

  byte error, address;
  int nDevices = 0;

  for (address = 1; address < 127; address++) {
    Wire.beginTransmission(address);
    error = Wire.endTransmission();

    if (error == 0) {
      Serial.print("找到 I2C 裝置！位址: 0x");
      if (address < 16) Serial.print("0");
      Serial.println(address, HEX);
      nDevices++;
    }
  }

  if (nDevices == 0) {
    Serial.println("未找到任何裝置，請檢查 5V 電源與接線！");
  }
}

void loop() {
  // 掃描一次即可，loop 保持空白
}
```
