上一堂課我們使用板載LED燈結合Serial Port輸出輸入，並實作了摩斯密碼專案。
本堂課開始，我們會逐步介紹各個零件與感測器，也就意味著課程將正式進入開始自己接電路板的時候了。
本堂課會使用到的元件如下：
- ESP32-S3開發板
- 麵包板
- 紅綠燈模組

課程目標：
- 理解外接模組（共陰極/共陽極概念與共用接地GND）的物理連接方式。
- 多腳位控制與陣列應用。
- 狀態機（state machine）雛形：：透過紅綠燈「綠燈 → 黃燈 → 紅燈」的固定順序與時間軸，建立系統狀態切換的邏輯觀念。
- 進階狀態控制：從delay()到millis()。

---
- 一般來說，大多數的課程會教你使用單顆的LED燈（同學手上的材料盒裡就有好幾顆不同顏色的LED），如果直接使用這些LED燈需要外加電阻，才不會把LED燈燒掉。
- 本學期課程使用的紅綠燈模組，已經內建R, Y, G三個腳位，分別對應紅、黃、綠燈，並提供三顆LED共用的負極腳位（GND）。
- 因此我們首先要做的是，把開發板的GND跟紅綠燈模組的GND連接起來，並選擇三個GPIO腳位給三種不同的顏色。
```text
[ ESP32-S3 ]            [ 紅綠燈模組 ]
  GPIO 19   ------------->   R (紅燈)
  GPIO 20   ------------->   Y (黃燈)
  GPIO 21   ------------->   G (綠燈)
    GND     ------------->  GND (接地)
```

## 使用陣列定義pinMode
- `int leds[] = {19, 20, 21};`：將多個GPIO編號定義在陣列中。
- `sizeof(leds) / sizeof(leds[0])`：動態計算陣列中的元素個數。

```c=
// 定義腳位：紅(19)、黃(20)、綠(21)
int redPin = 19;
int yellowPin = 20;
int greenPin = 21;

// 使用陣列整理所有外接腳位
int leds[] = {redPin, yellowPin, greenPin};
int numLeds = sizeof(leds) / sizeof(leds[0]);

void setup() {
  // 利用迴圈初始化所有 LED 腳位
  for (int i = 0; i < numLeds; i++) {
    pinMode(leds[i], OUTPUT);
    digitalWrite(leds[i], LOW); // 預設全部關閉
  }
}

// 關閉所有燈號
void setAllOff() {
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(leds[i], LOW);
  }
}

void loop() {
  // 1. 綠燈亮 3 秒
  setAllOff();
  digitalWrite(greenPin, HIGH);
  delay(3000);

  // 2. 黃燈亮 1 秒
  setAllOff();
  digitalWrite(yellowPin, HIGH);
  delay(1000);

  // 3. 紅燈亮 3 秒
  setAllOff();
  digitalWrite(redPin, HIGH);
  delay(3000);
}
```
