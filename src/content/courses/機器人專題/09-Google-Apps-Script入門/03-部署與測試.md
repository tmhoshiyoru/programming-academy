上一節寫好的 GAS，已經知道怎麼把溫度和溼度寫進試算表。那 ESP32 要把資料送到哪裡？這一節先替程式取得一個網址，再用電腦送兩筆測試資料，看看哪一筆會進到表格。

## 第一步｜讓程式有一個收資料的網址

把 GAS 部署成「網頁應用程式」後，就會取得一個網址。當電腦或 ESP32 把資料送到這個網址，Google 就會呼叫你上一節寫好的 `doPost(e)`。

1. 回到練習用試算表的 Apps Script 編輯器，儲存程式。
2. 點右上角的「部署 → 新增部署作業」，類型選「網頁應用程式」。
3. 執行身分選「我」，GAS 才會以你的身分寫入試算表。存取權選「任何人」，讓沒有登入 Google 的 ESP32 也能送資料，接著依畫面完成部署與授權。如果學校帳號沒有這個選項，請使用老師提供的練習網址。
4. 複製以 `/exec` 結尾的網址，下一步會用到它。

把自己的部署網址存到 GAS 程式最上方的註解，方便第 10 章設定 ESP32 時直接複製。貼好後按「儲存」。

```javascript
// GAS 部署網址：https://script.google.com/macros/s/你的部署ID/exec
```

這是練習用試算表的寫入網址。拿到網址的人也能送資料，請自行保管。練習結束後可以封存部署。之後若改了程式，從「部署 → 管理部署作業」編輯原部署並選擇新版本，就能繼續用同一個網址。

## 第二步｜送一筆完整的資料

打開 Windows PowerShell。把第一行引號內的文字換成你剛複製的網址，再貼上執行。

```powershell
$url = '貼上以 /exec 結尾的網址'
'{"temperature":25,"humidity":60}' | curl.exe --silent --show-error --location --header 'Content-Type: application/json' --data-binary '@-' $url
```

看到 `OK` 後，打開「溫溼度紀錄」分頁。找到最後一列，確認 A 欄有寫入時間，B 欄是 25，C 欄是 60。若使用老師提供的網址，請用老師分配給你這組的數值核對紀錄。

## 第三步｜故意少送一個欄位

在同一個 PowerShell 視窗貼上下面這行。先猜猜看，只送溫度時，試算表會多出一列嗎？

```powershell
'{"temperature":25}' | curl.exe --silent --show-error --location --header 'Content-Type: application/json' --data-binary '@-' $url
```

這次應該看到 `ERROR: invalid reading`。回到試算表看最後一列，確認仍是上一步寫入的完整紀錄。這就是上一節的資料檢查在發揮作用。

## 結果和預期不同時

- 看到 Google 登入畫面，先檢查部署是否允許未登入的裝置存取。
- 看到 `ERROR: sheet not found`，核對試算表 ID 和底部分頁是否叫「溫溼度紀錄」。

指令裡的 `--location` 會跟著 Google 提供的轉址去讀取 `OK` 或 `ERROR`。到了第 10 章，ESP32 也會做這一步。 [Google Content Service](https://developers.google.com/apps-script/guides/content#redirects)
