## 課程目標：
- 理解4x3矩陣鍵盤的運作原理，並學會使用`keypad`函式庫讀取單一按鍵。
- 結合矩陣鍵盤與其他功能互動。

## 一、硬體接線與原理說明
1. 矩陣鍵盤原理
4x3 矩陣鍵盤共有 12 個按鍵，採用 4 行（Rows）$\times$ 3 列（Cols） 的網格設計，僅需 7 個 GPIO 引腳即可讀取所有按鍵。
2. ESP32-S3 接線對照表

|鍵盤接腳名稱|腳位類型|GPIO引腳|
|:---:|:---:|:---:|
|Row1|行1|GPIO 4|
|Row2|行2|GPIO 5|
|Row3|行3|GPIO 6|
|Row4|行4|GPIO 7|
|Col1|列1|GPIO 15|
|Col2|列2|GPIO 16|
|Col3|列3|GPIO 17|

## 二、函式庫與使用語法
在 Arduino IDE 中使用矩陣鍵盤前，請先確認已安裝 `Keypad` 程式庫。

語法解析
1. `Keypad customKeypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);`
 - 建立一個 4x3 矩陣鍵盤物件，傳入按鍵配置地圖、行/列引腳陣列與維度。

2. `char key = customKeypad.getKey();`
 - 讀取當前按下的按鍵字元。若無按鍵按下，傳回 NO_KEY（即 0 或 '\0'）。

 ```c=
 #include <Keypad.h>

// 定義 4x3 矩陣維度
const byte ROWS = 4;
const byte COLS = 3;

// 定義 4x3 鍵盤按鍵配置
char keys[ROWS][COLS] = {
  {'1', '2', '3'},
  {'4', '5', '6'},
  {'7', '8', '9'},
  {'*', '0', '#'}
};

// 指定 ESP32-S3 GPIO 腳位
byte rowPins[ROWS] = {4, 5, 6, 7};    // Row 1~4
byte colPins[COLS] = {15, 16, 17};   // Col 1~3

Keypad customKeypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

void setup() {
  Serial.begin(115200);
  Serial.println("====================================");
  Serial.println(" ESP32-S3 4x3 Keypad Scan Test");
  Serial.println(" Press any key on the keypad...");
  Serial.println("====================================");
}

void loop() {
  // 讀取當前按下的按鍵
  char key = customKeypad.getKey();

  // 若 key 不為 0 (代表有按鍵按下)
  if (key) {
    Serial.print("Pressed Key: ");
    Serial.println(key);
  }
}
```
