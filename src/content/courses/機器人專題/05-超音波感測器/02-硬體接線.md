接下來我們要先完成 HC-SR04 超音波感測器與 ESP32 的硬體連接。為了確保後續整合專案時不會發生 GPIO 腳位衝突，我們目前先完全避開先前專案引腳的接線配置。

※將來學到的感測器越來越多，難免會碰到腳位衝突，這時就要對使用的感測器做出取捨了。

## 一、 GPIO 規劃
在安排接線時，我們必須避開先前章節已使用的腳位：
- 紅綠燈模組：GPIO 19, 20, 21（紅、黃、綠）
- 4x3 矩陣鍵盤：GPIO 4, 5, 6, 7（Row 1-4）與 GPIO 15, 16, 17（Col 1-3）
腳位選擇策略
我們挑選開發板右側空閒的 GPIO 41 與 GPIO 42 來控制超音波感測器：
- Trig (觸發腳) $\rightarrow$ GPIO 41
- Echo (回波腳) $\rightarrow$ GPIO 42

## 二、 接線對照表 (Wiring Table)
**（為避免意外發生，請先拔除 ESP32 電源）**
接下來我們會使用到杜邦線，手上的材料有分成一整組的和單條的，首先介紹一下線上面接頭的功能：
- 針頭 / 凸頭（Pin）：有金屬針腳伸出來的那一端。
- 孔頭 / 凹頭（Socket / Header）：有金屬孔洞可以插進去的那一端。

請拿取 4 根杜邦線（雙針線 * 3 、單針單孔線 * 1），參照老師的接線配置，ESP32 露在麵包板外的一側使用單針單孔線，其餘使用雙針線的線。

## 三、 硬體接線檢查清單 (Checklist)
在上電測試前，請完成以下三點硬體檢查，培養良好的電路除錯習慣：

- [ ] 電源極性確認：VCC 是否確實連接至 5V (VIN)，GND 是否連接至 GND？（接反可能導致晶片發熱損壞）
- [ ] Trig / Echo 腳位對齊：Trig 是否接到 GPIO 41？Echo 是否接到 GPIO 42？（兩者接反會導致一直讀到 0 cm）
- [ ] 檢查 GPIO 19-21 與 GPIO 4-7, 15-17 是否保持空置（或維持先前的紅綠燈/鍵盤接線狀態未被干擾）。
