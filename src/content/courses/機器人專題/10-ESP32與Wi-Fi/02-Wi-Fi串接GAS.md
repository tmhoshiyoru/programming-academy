沿用上一節的 Wi-Fi 程式。這次只送一筆固定值，成功後再接回 DHT11。

## 為什麼 ESP32 需要憑證？

ESP32 要用 HTTPS 把資料送給 Google。憑證就像網站的身分證，ESP32 會用程式裡的信任資料，檢查連線對象是不是網址所指的 Google 伺服器。憑證有有效期限，所以程式會先校時，再建立 HTTPS 連線。

## 準備程式

1. 在上一節程式頂端加入以下四行。

```cpp
#include <HTTPClient.h>
#include <WiFiClientSecure.h>
#include <time.h>
#include "google_roots.h"
```

2. 在 Arduino IDE 草稿的分頁選單選「新增分頁」，命名為 `google_roots.h`。把本頁最下方的「憑證分頁」整段複製進去。這些是 Google 的公開根憑證，可以原樣使用。
3. 回到主程式，把下方的 `gasUrl` 換成第 9 章存到 GAS 註解、以 `/exec` 結尾的網址。

## 在 setup() 前加上傳送函式

GAS 完成寫入後，Google 可能把回覆導向另一個網址。程式只 POST 一次，再用 GET 取回文字回覆。這樣追蹤回覆時也不會再次送出寫入請求。

```cpp
const char* gasUrl = "貼上 GAS 的 /exec 網址";

bool syncClock() {
  configTime(0, 0, "time.google.com", "pool.ntp.org");
  const unsigned long started = millis();
  while (time(nullptr) < 1700000000 && millis() - started < 15000) {
    delay(250);
  }
  return time(nullptr) >= 1700000000;
}

bool sendReading(float temperature, float humidity) {
  if (WiFi.status() != WL_CONNECTED) {
    Serial.println("Wi-Fi disconnected");
    return false;
  }

  char payload[80];
  snprintf(payload, sizeof(payload),
           "{\"temperature\":%.1f,\"humidity\":%.1f}", temperature, humidity);

  WiFiClientSecure client;
  client.setCACert(googleRoots);
  HTTPClient http;
  http.setConnectTimeout(5000);
  http.setTimeout(5000);
  http.setFollowRedirects(HTTPC_DISABLE_FOLLOW_REDIRECTS);

  if (!http.begin(client, gasUrl)) return false;
  http.addHeader("Content-Type", "application/json");
  int status = http.POST(String(payload));

  if (status == 302 || status == 303) {
    const String redirect = http.getLocation();
    http.end();

    if (!redirect.startsWith("https://script.googleusercontent.com/")) {
      Serial.println("Unexpected redirect. Check GAS deployment access.");
      return false;
    }
    if (!http.begin(client, redirect)) return false;
    status = http.GET();
  }

  String reply = status == 200 ? http.getString() : "";
  http.end();
  reply.trim();
  Serial.printf("HTTP %d\n", status);
  if (reply.length()) Serial.println(reply);
  return status == 200 && reply == "OK";
}
```

把上一節 `setup()` 內的 `connectWiFi();` 換成以下程式，`loop()` 先留空。

```cpp
  if (!connectWiFi()) return;
  if (!syncClock()) {
    Serial.println("Clock sync timeout");
    return;
  }
  sendReading(25, 60);
```

## 驗收

序列監控視窗顯示 `OK`，試算表應多一列 25 °C、60 % RH。若 HTTP 回覆未收到，先看工作表是否已寫入，再決定要不要重送。看到 `ERROR` 就回第 9 章檢查 GAS 的訊息；看到 `Clock sync timeout`，表示板子還沒取得時間，先確認 Wi-Fi 能連外且可連到網路校時服務。HTTPS 連線失敗時，核對 `google_roots.h` 是否完整貼上，以及網址是否為第 9 章的 `/exec` 網址。

[Google Content Service 的重新導向說明](https://developers.google.com/apps-script/guides/content#redirects) · [ESP32 HTTPClient](https://github.com/espressif/arduino-esp32/blob/master/libraries/HTTPClient/src/HTTPClient.h)
