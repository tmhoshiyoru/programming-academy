## 題目

ROT13 是一種替換式密碼，會把每個英文字母換成字母表中往後第 13 個字母。超過 Z 或 z 時就繞回開頭。大寫仍是大寫，小寫仍是小寫。空白、數字、標點及其他字元照原樣輸出。由於英文字母有 26 個，同一段文字轉換兩次就會回到原文。

- **輸入**　一段最多 5000 字元的文字。
- **輸出**　依原順序輸出轉換後的文字。

### 範例輸入

```text
It may be famous for its meandering medinas and the scenic Atlas Mountains, but Morocco might soon make its name as a solar superpower.
```

### 範例輸出

```text
Vg znl or snzbhf sbe vgf zrnaqrevat zrqvanf naq gur fpravp Ngynf Zbhagnvaf, ohg Zbebppb zvtug fbba znxr vgf anzr nf n fbyne fhcrecbjre.
```

## 觀察動畫

輸入文字或載入範例，再按「執行」。字元列會往上移，掃描方塊從下方往右走。英文字母會像轉輪一樣轉到目標字母，其他符號直接送到輸出欄。長文會加快播放，並分批更新畫面。畫面用 ␣、↵ 和 ⇥ 標示空格、換行和定位字元，輸出欄保留原始字元。

```game-js
const source = document.querySelector('#source');
const result = document.querySelector('#result');
const status = document.querySelector('#status');
const step = document.querySelector('#step');
const viewport = document.querySelector('#viewport');
const cells = document.querySelector('#cells');
const scanner = document.querySelector('#scanner');
const reducedMotion = matchMedia('(prefers-reduced-motion: reduce)');
const sample = "It may be famous for its meandering medinas and the scenic Atlas Mountains, but Morocco might soon make its name as a solar superpower.";
let runId = 0;
let previousExample = -1;
const examples = [
  'A zebra crossed the road at 7 AM.',
  'Meet me by the library after lunch!',
  'Why did the robot bring an umbrella?',
  'The secret code is hidden in Box 13.',
  'Pack my box with five dozen liquor jugs.',
  'Hello, world! Can you read this message?',
];

function reset() {
  runId += 1;
  cells.replaceChildren();
  cells.classList.remove('raised');
  scanner.hidden = true;
  viewport.hidden = true;
  result.value = '';
  step.textContent = '';
  return runId;
}

function pause(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

function displayChar(char) {
  if (char === ' ') return '␣';
  if (char === '\n') return '↵';
  if (char === '\t') return '⇥';
  return char;
}

function loadExample(text) {
  reset();
  source.value = text;
  status.textContent = '已載入範例，按「執行」開始。';
}

document.querySelector('#example').addEventListener('click', () => loadExample(sample));
document.querySelector('#random-example').addEventListener('click', () => {
  const choices = previousExample < 0 ? examples.length : examples.length - 1;
  let index = Math.floor(Math.random() * choices);
  if (previousExample >= 0 && index >= previousExample) index += 1;
  previousExample = index;
  loadExample(examples[index]);
});

document.querySelector('#run').addEventListener('click', async () => {
  const currentRun = reset();
  const chars = Array.from(source.value);
  if (chars.length === 0 || chars.length > 5000) {
    status.textContent = '請輸入 1 到 5000 個字元。';
    source.focus();
    return;
  }

  const tiles = chars.map((char) => {
    const tile = document.createElement('div');
    tile.className = 'cell';
    const glyph = document.createElement('span');
    glyph.textContent = displayChar(char);
    tile.append(glyph);
    return { tile, glyph };
  });
  cells.append(...tiles.map(({ tile }) => tile));
  viewport.hidden = false;
  viewport.scrollLeft = 0;
  status.textContent = '先排列原文，再把字元列往上移。';
  await pause(450);
  if (currentRun !== runId) return;
  cells.classList.add('raised');
  scanner.style.setProperty('--travel', '0ms');
  scanner.style.left = '2.55rem';
  await pause(400);
  if (currentRun !== runId) return;

  scanner.textContent = '掃描';
  scanner.hidden = false;
  status.textContent = '從左往右掃描，轉換結果會依序出現在輸出欄。';
  // 長文以批次更新畫面，仍依序轉換並輸出每個字元。
  const batchSize = Math.max(1, Math.ceil(chars.length / 240));
  const travel = chars.length <= 40 ? 190 : 75;
  const turns = chars.length <= 40 ? 13 : chars.length <= sample.length ? 5 : 3;
  const turnDuration = chars.length <= sample.length ? 55 : 32;
  scanner.style.setProperty('--travel', travel + 'ms');
  let output = '';
  let active;

  for (let start = 0; start < chars.length; start += batchSize) {
    const { tile, glyph } = tiles[start];
    const center = tile.offsetLeft + tile.offsetWidth / 2;
    scanner.style.left = center + 'px';
    viewport.scrollTo({ left: center - viewport.clientWidth / 2, behavior: 'instant' });
    await pause(travel);
    if (currentRun !== runId) return;
    active?.classList.remove('active');
    tile.classList.add('active');
    active = tile;

    for (let index = start; index < Math.min(start + batchSize, chars.length); index += 1) {
      const char = chars[index];
      if (!/^[A-Za-z]$/.test(char)) {
        step.textContent = displayChar(char) + ' 原樣輸出';
        output += char;
        continue;
      }

      const base = char >= 'a' ? 97 : 65;
      const offset = char.charCodeAt(0) - base;
      const target = String.fromCharCode(base + (offset + 13) % 26);
      const current = tiles[index];
      if (current.glyph === glyph && !reducedMotion.matches) {
        step.textContent = char + ' 往後轉 13 位';
        for (let turn = 1; turn <= turns; turn += 1) {
          const shift = Math.round(13 * turn / turns);
          current.glyph.textContent = String.fromCharCode(base + (offset + shift) % 26);
          current.glyph.animate(
            [{ transform: 'translateY(65%)', opacity: .25 }, { transform: 'translateY(0)', opacity: 1 }],
            { duration: turnDuration, easing: 'ease-out' },
          );
          await pause(turnDuration);
          if (currentRun !== runId) return;
        }
      }
      current.glyph.textContent = target;
      current.tile.classList.add('converted');
      step.textContent = char + ' → ' + target;
      output += target;
    }
    result.value = output;
  }

  active?.classList.remove('active');
  status.textContent = '轉換完成，共處理 ' + chars.length + ' 個字元。';
});
```
