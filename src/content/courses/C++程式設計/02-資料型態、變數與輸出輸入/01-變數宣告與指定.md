## 一、替資料取一個名字

前一章把文字直接寫在 `cout` 裡。如果分數會改變，可以把分數存進一個有名字的位置，再透過名稱使用它。這就是**變數**。

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 80;
    cout << score << endl;
    return 0;
}
```

輸出結果：

```text
80
```

讀取 `score` 時，程式使用的是變數目前的值。`cout << score;` 輸出數值，`cout << "score";` 則輸出雙引號裡的文字。

## 二、宣告時指定型態、名稱與初值

```cpp
int score = 80;
```

- `int`：資料型態，這裡先用來存整數。
- `score`：變數名稱。
- `80`：初始值。
- `;`：這個宣告的結尾。

**宣告**是建立變數；在建立時給它第一個值，叫做**初始化**。本課先使用 `int score = 80;` 這種寫法。

名稱先以英文字母開頭，後面可以使用英文字母、數字與底線，例如 `score`、`studentAge`、`student_age`。多個單字可以像 `studentAge` 一樣用大小寫區分，或像 `student_age` 一樣用單一底線連接。名稱會區分大小寫；選擇像 `score` 這樣能說明用途的名稱，把 `int`、`return` 等關鍵字留給程式語法使用。

## 三、指定新值，更新變數

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 80;
    cout << score << endl;

    score = 95;
    cout << score << endl;
    return 0;
}
```

輸出結果：

```text
80
95
```

`score = 95;` 會把 `95` **指定給** `score`，把原本的 `80` 換掉。這裡的 `=` 表示指定，不是數學中判斷兩邊是否相等的意思。

第一次建立時寫 `int score = 80;`，用 `int` 說明型態；後面更新同一個變數時，直接寫 `score = 95;`。

## 四、把一個變數的值交給另一個變數

```cpp
int score = 80;
int saved = score;
score = 95;
cout << score << " " << saved << endl;
```

`saved` 取得的是當時的值 `80`，之後兩個變數各自保留自己的內容。把 `score` 改為 `95` 後，`saved` 仍是 `80`，因此輸出是 `95 80`。

## 五、先給初值，再讀取

```cpp
int age = 0;
```

寫成 `int age = 0;`，就能確定 `age` 從 `0` 開始。宣告時給初值，再讀取或更新變數，是本課先練習的習慣。

**使用變數的值之前，要先給它一個值。** 函式裡若只寫 `int age;`，這個宣告會建立變數，初始值則仍待你指定。
