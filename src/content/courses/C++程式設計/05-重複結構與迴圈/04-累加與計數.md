## 一、用變數保留前幾輪的成果

計算 1 到 n 的總和時，可以準備一個 `sum`。每輪把新的數加進去，迴圈結束時，它就裝著完整總和。

同一個迴圈也能順便計算遇到幾個偶數，用 `evenCount` 記錄。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;
    int sum = 0;
    int evenCount = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
        if (i % 2 == 0) {
            evenCount++;
        }
    }
    cout << sum << endl;
    cout << evenCount << endl;
    return 0;
}
```

輸出結果：

```text
15
2
```

第一行是總和，第二行是偶數個數。當 n = 5 時，總和為 15，偶數 2、4 共兩個。

## 二、累加和計數各自在做什麼？

`sum += i;` 把**目前的值**加入總和；`evenCount++;` 則只在條件成立時，把**個數**加 1。兩者的初值都是 0，表示開始前尚未累積資料。

sum 變化是 0 → 1 → 3 → 6 → 10 → 15。evenCount 則只有遇到 2、4 時改變。

## 三、初值與建立位置

累積用的變數要放在迴圈前面，才能保留前一輪的結果。若把 `int sum = 0;` 放進每輪區塊，每輪就會重新從 0 開始。

做連乘時，起始值通常是 1，例如：

~~~cpp
int product = 1;
for (int i = 1; i <= 4; i++) {
    product *= i;
}
cout << product << endl;
~~~

結果是 24。乘法從 1 開始，因為乘以 1 會保留第一個數的值。
