## 一、一邊走訪，一邊保留目前的答案

找最大值可以想成接力比較：先拿一個候選答案，遇到更大的數就換成它。找最小值也用同樣的方法。

```cpp
#include <iostream>
using namespace std;

int main() {
    int number[5] = {3, 9, -2, 7, 5};
    int largest = number[0];
    int smallest = number[0];
    for (int i = 1; i < 5; i++) {
        if (number[i] > largest) {
            largest = number[i];
        }
        if (number[i] < smallest) {
            smallest = number[i];
        }
    }
    cout << largest << endl;
    cout << smallest << endl;
    return 0;
}
```

輸出結果：

```text
9
-2
```

`largest` 和 `smallest` 記錄「目前看過的資料」的最大與最小值。每輪完成後，這兩個答案就多涵蓋了一筆資料。

## 二、從第一筆資料開始

本例的陣列固定有五筆資料，因此能直接使用 `number[0]` 當初值，再從索引 1 往後比較。

這樣做也能自然處理全部是負數的資料。例如 -8、-3、-12、-1、-6 的最大值是 -1，初值來自資料本身，就能一路更新到正確答案。

## 三、相同的數也能比較

當新數和目前最大值一樣，`>` 的結果是 false，保留現有答案即可。如果想同時記錄最大值的位置，可以再用一個變數存索引，更新最大值時一起更新它。
