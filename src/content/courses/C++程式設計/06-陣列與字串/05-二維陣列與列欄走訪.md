## 一、把資料排成表格

座位、棋盤、每週每日的紀錄，都可以用「列、欄」描述位置。**二維陣列**讓我們用兩個索引取得一格資料。

```cpp
#include <iostream>
using namespace std;

int main() {
    int grid[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int total = 0;
    for (int row = 0; row < 2; row++) {
        for (int column = 0; column < 3; column++) {
            total += grid[row][column];
        }
    }
    cout << total << endl;
    return 0;
}
```

輸出結果：

```text
21
```

`grid[2][3]` 有二列、每列三個元素，共六格。存取時先寫列索引，再寫欄索引：`grid[1][2]` 是第二列的第三格。

## 二、兩個方向各自從 0 開始

本例 row 的合法範圍是 0 到 1，column 的合法範圍是 0 到 2。初始化的外層大括號包住整張表，內層每一組大括號則代表一列。

~~~cpp
grid[0][1] = 20;
cout << grid[0][1] << endl;
~~~

這段會修改第一列第二欄，再輸出 20。

## 三、接上巢狀迴圈

外層固定目前的 row，內層讓 column 走完該列。每次進入新的一列，column 都從 0 開始。

把 `total += grid[row][column];` 換成 `cin >> grid[row][column];`，就能依照同樣的順序填入資料。想要一列一列輸出時，則在內層輸出數字及空格，內層完成後再換行。
