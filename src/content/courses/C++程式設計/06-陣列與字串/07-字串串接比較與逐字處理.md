## 一、把兩段文字接起來

string 可以使用 `+` 串接文字，也可以使用 `+=` 把新內容接到原字串後面。

~~~cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string first = "Hello";
    string message = first + ", C++";
    message += "!";
    cout << message << endl;
    return 0;
}
~~~

輸出是 `Hello, C++!`。這裡的加號在串接字串；兩個整數相加時，才是算術加法。串接時使用 string 變數，就能清楚地讓程式取得字串資料。

## 二、用 == 比較整段內容

~~~cpp
string answer = "yes";
if (answer == "yes") {
    cout << "OK" << endl;
}
~~~

string 的 `==` 會比較整段內容。`"yes"` 和 `"Yes"` 的大小寫不同，因此比較結果是 false。`!=` 則可以判斷兩段內容是否不同。

## 三、把條件判斷放進逐字走訪

要數出 banana 裡有幾個 a，可以逐一取得 word[i]，符合目標時就把 count 加 1。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "banana";
    char target = 'a';
    int n = word.size();
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (word[i] == target) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

輸出結果：

```text
3
```

每輪只檢查一個字元，完整走訪後就得到總個數。當字串長度為 0，迴圈執行零次，答案自然保留為 0。
