## 一、一格一格找目標

想知道某個數有沒有出現在陣列裡，可以從第一格開始比較。這種依序檢查資料的方法叫作**線性搜尋**。

```cpp
#include <iostream>
using namespace std;

int main() {
    int number[5] = {4, 7, 4, 9, 2};
    int target = 4;
    int position = -1;
    for (int i = 0; i < 5; i++) {
        if (number[i] == target) {
            position = i;
            break;
        }
    }
    cout << position << endl;
    return 0;
}
```

輸出結果：

```text
0
```

本例尋找 4。它在索引 0 就出現，所以 position 變成 0，break 結束迴圈。後面還有另一個 4，這次搜尋在找到第一個時就完成工作。

## 二、用 -1 表示還沒找到

合法索引從 0 開始，所以可以選擇 -1 當作「尚未找到」的記號。若全部比較完都沒有相同的數，position 就會保留 -1。

輸出的 position 是**索引**。若要顯示「第幾個」，找到後可以使用 `position + 1`；仍是 -1 時，則顯示適合的未找到訊息。

## 三、想找全部的位置時

如果希望找出所有的 4，可以在相等時直接輸出 i，並讓迴圈繼續走完。若只想知道總共幾個，則在相等時把計數加 1。
