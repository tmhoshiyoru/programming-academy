## 一、讓迴圈依序走過每一格

依序處理陣列中的元素，叫作**走訪陣列**。索引本身可以是變數，因此能用迴圈讓 i 從 0 走到 4。

```cpp
#include <iostream>
using namespace std;

int main() {
    int score[5] = {72, 85, 60, 91, 78};
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += score[i];
    }
    double average = sum / 5.0;
    cout << sum << endl;
    cout << average << endl;
    return 0;
}
```

輸出結果：

```text
386
77.2
```

`score[i]` 會隨 i 改變：第一輪是 score[0]，下一輪是 score[1]，直到 score[4]。每輪只處理一格，最後 sum 就是五筆資料的總和。

## 二、起點是 0，條件使用小於長度

`i < 5` 讓 i 的值依序是 0、1、2、3、4。當 i 變成 5 時，條件為 false，陣列存取的指令就會略過。

平均使用 `sum / 5.0`。分母帶有小數，這次除法會保留小數結果；若兩邊都是整數，`sum / 5` 則會先取得整數商，之後才放進 average。

## 三、也可以用同一種方式輸入

~~~cpp
int score[5] = {0};
for (int i = 0; i < 5; i++) {
    cin >> score[i];
}
~~~

這段會按順序把五次讀到的整數放進五個位置。陣列保存資料後，可以接著計算總和、查詢個別分數，或再走訪一次做其他工作。
