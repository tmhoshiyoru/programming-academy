## 一、用一個名字管理一排資料

五位同學的分數可以放在五個變數裡，也可以用一個**陣列**整齊地存成一排。陣列中的每個位置叫作**元素**，這一排元素使用相同的資料型態。

```cpp
#include <iostream>
using namespace std;

int main() {
    int score[5] = {72, 85, 60, 91, 78};
    cout << score[1] << endl;
    score[1] = 90;
    cout << score[1] << endl;
    return 0;
}
```

輸出結果：

```text
85
90
```

`int score[5]` 建立五個 int 位置。大括號內的初值依順序放進去，`score[0]` 是 72，`score[1]` 是 85，依此類推。

## 二、索引從 0 開始

方括號中的編號叫作**索引**。長度為 5 的陣列，可用索引為 **0、1、2、3、4**。

- 宣告時的 `[5]`：表示建立五個元素。
- 使用時的 `score[2]`：表示取得第三個元素。
- `score[2] = 100;`：把第三個元素改成 100。

**不要把 `score[5]` 當成第五個元素。** 它已經超出這個陣列的範圍。C++ 的這種陣列不會自動替你擴充位置；存取範圍外的資料會使程式的行為失去保障。

## 三、初始值可以怎麼寫？

~~~cpp
int count[4] = {0};
int number[4] = {7, 8};
~~~

第一排的四個元素都是 0。第二排前兩個是 7、8，剩下的元素也會初始化為 0。先替資料設定初值，再開始使用，狀態會很清楚。

本章先練習長度直接寫在宣告裡的陣列，例如 `int score[5]`。之後再介紹如何依資料量選擇其他容器。
