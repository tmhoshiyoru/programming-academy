## 一、把字串看成排好順序的字元

第二章已用過 char 和 string。現在接著用索引取得字串中的某個字元，並觀察長度。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word = "cat";
    cout << word.size() << endl;
    cout << word[0] << endl;
    word[0] = 'C';
    cout << word << endl;
    return 0;
}
```

輸出結果：

```text
3
c
Cat
```

`word.size()` 取得長度，`word.length()` 也能取得相同結果。這裡的 cat 有三個英文字元，可用索引是 0、1、2。

## 二、取得與修改單一字元

`word[0]` 是一個字元，所以修改時右邊寫成單引號的 `'C'`。修改完成後，`cout << word` 仍會輸出整個字串。

走訪長度為 n 的字串時，使用 `i < n`，依序處理索引 0 到 n - 1。空字串 `""` 的長度是 0，這時就沒有可以讀取的內容位置。

## 三、本章先以英文字母與數字練習

本篇範例使用 ASCII 英文字母，長度與畫面上的字元個數一致。中文在常見的 UTF-8 編碼中，一個字可能佔多個位元組；string 的 size 計算的是儲存單位數，這時就和看到的中文字數不同。中文的拆字處理之後再進一步介紹。

`cin >> word;` 仍是先前介紹的讀入方式：讀取一段以空白分隔的文字。本章先使用這種輸入格式。
