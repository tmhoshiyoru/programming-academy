## 一、先把問題寫成可以判斷的條件

「分數至少 60 分」可以寫成：

```cpp
score >= 60
```

如果 `score` 是 `75`，結果是 `true`；如果是 `50`，結果是 `false`。比較兩個值，就能得到前一章學過的布林值。

| 比較運算子 | 意思 | 代入 `score = 75` 的結果 |
| --- | --- | --- |
| `==` | 相等 | `score == 60` → `false` |
| `!=` | 不相等 | `score != 60` → `true` |
| `>` | 大於 | `score > 60` → `true` |
| `<` | 小於 | `score < 60` → `false` |
| `>=` | 大於或等於 | `score >= 60` → `true` |
| `<=` | 小於或等於 | `score <= 60` → `false` |

**比較是否相等使用 `==`，指定新值使用 `=`。** 例如 `score == 60` 是在問「分數等於 60 嗎？」，`score = 60;` 則是把分數改成 60。

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 75;
    bool passed = score >= 60;
    cout << passed << endl;
    return 0;
}
```

輸出 `1`，表示 `passed` 是 `true`。如果改成 `score = 50`，就會輸出代表 `false` 的 `0`。

### 特別留意：不要把比較的 == 寫成指定的 =

少一個等號，程式做的事情就變了，而且**可能仍然編譯成功，卻得到錯誤的判斷結果**。比較下面兩種情況：

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 75;

    bool same = (score == 60);       // 比較：75 等於 60 嗎？
    cout << same << " " << score << endl;

    bool mistaken = (score = 60);    // 常見誤寫：先把 score 改成 60
    cout << mistaken << " " << score << endl;
    return 0;
}
```

輸出結果：

```text
0 75
1 60
```

- `score == 60` 比較後得到 `false`，原本的分數仍然是 `75`。
- `score = 60` 先把分數改成 `60`，這個指定運算式的值也是 `60`。轉成 `bool` 時，非零值視為 `true`，所以 `mistaken` 變成 `true`。

**`=` 會更新資料，`==` 才是在比較。** 後面學到 `if` 時，像 `if (score = 60)` 這種誤寫，會改掉分數，還把條件當成成立；原本想問的「分數是否等於 60」就沒有被正確判斷。

## 二、用「而且」、「或者」、「相反」組合條件

假設有兩個條件：

- `passed`：分數是否及格。
- `hasCard`：是否帶了識別證。

| 邏輯運算子 | 讀法 | 成立的情況 |
| --- | --- | --- |
| `&&` | 而且（AND） | 左右兩個條件都成立 |
| `\|\|` | 或者（OR） | 至少有一個條件成立 |
| `!` | 相反（NOT） | 把 `true`、`false` 對調 |

`passed && hasCard` 的意思是「及格，而且帶了識別證」。`passed || hasCard` 的意思是「及格，或者帶了識別證」，兩個都成立也符合這個「或者」。

`!passed` 的意思是把及格狀態反過來：`passed` 是 `true` 時，`!passed` 就是 `false`。

## 三、把所有組合列出來

下面這種把各種輸入與結果排列在一起的表，叫作**真值表**。

| a | b | `a && b` | `a \|\| b` | `!a` |
| --- | --- | --- | --- | --- |
| `false` | `false` | `false` | `false` | `true` |
| `false` | `true` | `false` | `true` | `true` |
| `true` | `false` | `false` | `true` | `false` |
| `true` | `true` | `true` | `true` | `false` |

可以先用日常語言讀一次，再對照表格。例如「下雨而且帶傘」，要同時符合兩件事；「搭公車或者搭捷運」，則至少符合其中一件事。

## 四、比較和邏輯運算可以一起使用

「年齡介於 15 到 18 歲，包含 15 和 18」，可以拆成兩個條件：

```cpp
(age >= 15) && (age <= 18)
```

這種寫法和數學中的 $15 \leq age \leq 18$ 表達同一個範圍。程式裡用兩次比較，再用 `&&` 連起來。

**不要直接把數學的連鎖比較寫成 `15 <= age <= 18`。** C++ 會把它組合成 `(15 <= age) <= 18`：先得到前半段的 `true` 或 `false`，再把它當成 `1` 或 `0`，拿去和 `18` 比較。

例如 `age` 是 `25`，雖然已經超出範圍，誤寫的運算式仍然會判斷為成立：

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 25;
    bool mistaken = 15 <= age <= 18;          // 常見誤寫
    bool inRange = (age >= 15) && (age <= 18);
    cout << mistaken << " " << inRange << endl;
    return 0;
}
```

輸出 `1 0`。誤寫的那一行會先算 `15 <= 25` 得到 `true`，接著算 `1 <= 18`，所以得到 `true`；正確的寫法會同時檢查下限與上限，因此得到 `false`。

這個誤寫在 `age` 小於 `15` 時也會出問題：前半段是 `false`，接著變成 `0 <= 18`，結果仍然是 `true`。**範圍判斷要拆成兩個比較，再用 `&&` 連接。**

```cpp
bool inRange = (age >= 15) && (age <= 18);
bool outside = !inRange;
```

先把每個條件用括號分組，再選擇 `&&`、`||` 或 `!`，就能把一句話拆成清楚的判斷。

## 五、條件確定後，可以提早得到結果

`&&` 先看左邊：左邊是 `false`，整體就確定是 `false`，右邊會略過。`||` 的左邊是 `true` 時，整體就確定是 `true`，右邊也會略過。這叫作**短路求值**。

例如 `(score >= 60) && hasCard`，如果分數是 `50`，第一個條件就足以決定整體結果。之後遇到較複雜的條件時，這個規則也能幫助安排判斷。
