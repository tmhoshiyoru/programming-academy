## 一、把熟悉的加減乘除寫成程式

| 運算子 | 意思 | 範例 | 結果 |
| --- | --- | --- | --- |
| `+` | 加法 | `7 + 2` | `9` |
| `-` | 減法 | `7 - 2` | `5` |
| `*` | 乘法 | `7 * 2` | `14` |
| `/` | 除法 | `7 / 2` | `3`（整數除法） |
| `%` | 求餘數 | `7 % 2` | `1` |

乘法用半形 `*`，除法用半形 `/`。運算元可以是數值、變數，也可以是括號中的運算式。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7;
    int b = 2;
    cout << a + b << endl;
    cout << a - b << endl;
    cout << a * b << endl;
    cout << a / b << endl;
    cout << a % b << endl;
    return 0;
}
```

輸出結果：

```text
9
5
14
3
1
```

## 二、整數除法與小數除法

**兩個整數相除時，結果也是整數，小數部分會朝 0 的方向捨去。**

```cpp
cout << 7 / 2 << endl;        // 3
cout << 7 / 2.0 << endl;      // 3.5
cout << -7 / 2 << endl;       // -3
```

如果需要小數結果，讓其中一個運算元使用浮點數即可。例如 `2.0` 是浮點數，`7 / 2.0` 會做小數除法。

```cpp
double average = 7 / 2;       // 先做整數除法，再把 3 存進 average
double average2 = 7 / 2.0;    // 先做小數除法，再把 3.5 存進 average2
```

運算的方式由運算元的型態決定，結果求出來後，才放進左邊的變數。

## 三、餘數可以用來拆分數量

`17 / 5` 的商是 `3`，`17 % 5` 的餘數是 `2`，對應到數學中的：

$$17 = 5 \times 3 + 2$$

例如把 `135` 分鐘拆成幾小時、幾分鐘：

```cpp
#include <iostream>
using namespace std;

int main() {
    int totalMinutes = 135;
    int hours = totalMinutes / 60;
    int minutes = totalMinutes % 60;
    cout << hours << " " << minutes << endl;
    return 0;
}
```

輸出 `2 15`，代表 2 小時 15 分鐘。之後也可以用 `% 2` 判斷奇偶、用 `% 10` 取得非負整數的個位數。

`%` 用於整數。當左邊是負數時，餘數可能是負的，例如 `-7 % 2` 是 `-1`，因為 `-7 = (-3) * 2 + (-1)`。

**做除法或求餘數時，除數要選擇非零的數。**

## 四、先乘除，後加減；括號先成一組

`*`、`/`、`%` 的優先順序相同，比 `+`、`-` 高。同一層、同樣優先順序的這些運算子，由左往右組合。

```cpp
cout << 2 + 3 * 4 << endl;       // 14
cout << (2 + 3) * 4 << endl;     // 20
cout << 20 / 5 * 2 << endl;      // (20 / 5) * 2，結果是 8
```

這是在決定運算式如何組合；把想先當成一組的部分加上括號，也能幫助閱讀。

## 五、用運算結果更新變數

```cpp
int score = 80;
score = score + 5;   // 先取得舊值 80，加 5 後，把 85 指定給 score
score += 5;         // 再加 5，score 變成 90
```

在這個整數例子中，`score += 5;` 可以看成 `score = score + 5;` 的簡寫。同樣也有 `-=`、`*=`、`/=`、`%=`。

### 每次加 1 或減 1：++ 與 --

如果每次都是加 `1`，還有更短的寫法：`count++;`。`++` 叫作**遞增運算子**，這裡可以讀成「把 count 加 1」。

當這些寫法**各自作為一整行指令**、用來更新這個整數變數時，作用如下：

| 完整寫法 | 簡寫 | 再簡寫 | 更新後的值 |
| --- | --- | --- | --- |
| `count = count + 1;` | `count += 1;` | `count++;` | 原本的值加 1 |
| `count = count - 1;` | `count -= 1;` | `count--;` | 原本的值減 1 |

`--` 叫作**遞減運算子**，可以讀成「把 count 減 1」。每一列的三種寫法選擇一種即可，例如下面用 `count++` 加 1，再用 `count--` 減 1：

```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 3;
    cout << count << endl;

    count++;                 // 和 count += 1; 一樣，把 count 更新為 4
    cout << count << endl;

    count--;                 // 和 count -= 1; 一樣，把 count 更新為 3
    cout << count << endl;
    return 0;
}
```

輸出結果：

```text
3
4
3
```

本篇先把「更新變數」與「輸出結果」分成兩行，清楚看到每次改變。之後在迴圈中，還會用 `++` 記錄次數。
