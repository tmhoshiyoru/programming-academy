## 一、先從一筆購物金額看起

一份點心 `80` 元，買 `3` 份，再加上 `20` 元運費，總金額可以寫成：

```cpp
80 * 3 + 20
```

這一段會算出 `260`，我們稱它為**運算式**。它把資料按照一定的規則組合起來，程式就能求出一個結果。

裡面有兩種角色：

- **運算元**：拿來參與運算的資料。這裡是 `80`、`3`、`20`。
- **運算子**：說明要做什麼操作的符號。這裡的 `*` 表示乘法，`+` 表示加法。

可以把運算元想成「材料」，運算子想成「處理材料的方法」。例如 `8 + 5`，就是把 `8` 和 `5` 這兩份資料交給加法處理。

## 二、運算元也可以來自變數

```cpp
#include <iostream>
using namespace std;

int main() {
    int price = 80;
    int count = 3;
    int fee = 20;
    int total = price * count + fee;

    cout << total << endl;
    return 0;
}
```

輸出結果：

```text
260
```

`price * count + fee` 會取用這三個變數目前的值。把數字放進變數之後，同一個運算式就能處理不同的單價、份數與運費。

在 `int total = price * count + fee;` 中，右邊先求出金額，再用這個結果作為 `total` 的初始值。

## 三、怎麼組成一個運算式？

先掌握三個重點：

1. **有資料可以使用。** 可以直接寫數值，也可以使用已宣告、已經有值的變數。
2. **依照運算子的寫法安排資料。** 例如加法寫成 `a + b`，左右各放一個運算元；`-a` 則用一個運算元，表示取相反數。
3. **讓資料型態適合這項操作。** 例如數字可以做乘法，整數可以求餘數；不同型態適合的操作會在後面各篇介紹。

運算式也可以很簡單：`42` 或 `price` 本身就是運算式，它們各自代表一個值。加入運算子之後，就能組成更大的運算式。

| 寫法 | 這段的意思 |
| --- | --- |
| `42` | 直接使用數值 42 |
| `price` | 取得 `price` 目前的值 |
| `price * count` | 單價乘上份數 |
| `price * count + fee` | 商品金額再加上運費 |
| `-price` | 取得 `price` 的相反數 |

## 四、括號可以把一部分當成一組

數學裡的先乘除、後加減，在這些算術運算式裡也適用：

```cpp
80 + 20 * 3       // 先算 20 * 3，結果是 140
(80 + 20) * 3     // 先把括號中的和當成一組，結果是 300
```

在 `(price + fee) * count` 中，整個 `(price + fee)` 可以當作乘法左邊的運算元。運算元除了單一數值，也可以是另一個運算式。

C++ 的乘法使用 `*`，像數學中的 `3(a + b)`，在程式裡寫成 `3 * (a + b)`。

      document.querySelector('#role').textContent = role === 'operand' ? text + ' 是運算元，這次使用的值是 ' + memory[text] + '。' : role === 'group' ? '括號把 price + fee 當成一組，這一組的結果再參與乘法。' : text === '-' && index === 0 ? '- 是取相反數的運算子，這裡搭配一個運算元 price。' : text + ' 是運算子，這裡把左右兩邊的資料做' + (text === '*' ? '乘法。' : '加法。');

## 五、把運算式放進一行指令

```cpp
int total = price * count + fee;
cout << total << endl;
```

第一行建立 `total`，並用運算式的結果作為初值；第二行輸出這個值。這些完整的指令叫作**敘述**。

本章先記住：運算式是用來求值的一部分，像 `price * count + fee`；分號則用來結束這裡的宣告或輸出敘述。

接下來會遇到三種運算：算術運算處理數量，邏輯運算判斷條件，位元運算處理整數裡的 `0`、`1`。
