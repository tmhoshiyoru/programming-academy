## 一、先認識一支完整的 C++ 程式

程式就是一組交給電腦的指令。這一課先讓電腦做一件簡單的事：在畫面上輸出一行文字。

先閱讀下面的完整範例，不需要馬上背起來。我們會逐行拆解它的用途。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
    return 0;
}
```

執行後，輸出結果是：

```text
Hello, C++!
```

可以先把整支程式分成兩部分：**前面準備要用的工具，接著在 `main` 裡寫下要執行的動作。**

| 行號 | 程式內容 | 這一行的用途 |
| --- | --- | --- |
| 1 | `#include <iostream>` | 引入標準輸入、輸出所需的標頭。 |
| 2 | `using namespace std;` | 讓我們可以直接使用 `std` 命名空間中的名稱，例如 `cout`。 |
| 3 | 空白行 | 分隔程式區域，方便閱讀，不會產生執行動作。 |
| 4 | `int main() {` | 定義主函式，並用左大括號開始主函式的內容。 |
| 5 | `cout << "Hello, C++!" << endl;` | 輸出文字，再換到下一行。 |
| 6 | `return 0;` | 結束主函式，回傳代表正常完成的狀態值 `0`。 |
| 7 | `}` | 用右大括號結束主函式的範圍。 |

## 二、把基本架構拆開來看

### 1. `#include <iostream>`：準備輸入、輸出的工具

`#include` 是前置處理指令，`iostream` 是 C++ 標準程式庫中與輸入、輸出有關的標頭。

這一課會使用 `cout` 輸出內容，所以先引入 `<iostream>`。請注意這一行前面有 `#`，結尾**不加分號**。

### 2. `using namespace std;`：簡化名稱的使用

標準程式庫中的許多名稱放在 `std` 命名空間中。加入這行後，在這份範例裡就可以直接使用 `cout`、`endl` 等名稱。

本課程的範例會統一使用 `using namespace std;`。它的結尾**需要分號**。

### 3. `int main() {`：主函式的開始

一般主控台 C++ 程式執行時，會進入 `main` 主函式。

- `int`：表示主函式回傳整數。
- `main`：主函式的名稱，大小寫要正確。
- `()`：函式的參數位置；這一課先保留空白。
- `{`：主函式內容的開始，之後要有配對的 `}`。

在大括號裡面，我們通常會把程式向右縮排，讓範圍更容易辨認。

### 4. `cout << "Hello, C++!" << endl;`：執行輸出

這是主函式中第一個要執行的動作：先輸出 `Hello, C++!`，再換行。`cout` 的用法會在下一篇詳細介紹。

### 5. `return 0;`：回報正常結束

`return` 會結束目前的函式。主函式回傳 `0`，表示程式正常完成。

**回傳和輸出是兩件事。** `return 0;` 不會在畫面輸出 `0`；如果要輸出數字，必須使用輸出指令。

### 6. `}`：主函式範圍的結束

右大括號與前面的左大括號配成一組。閱讀程式時，要能看出哪些指令被包在這一組括號內。

## 三、`main` 結尾的 `return 0;` 可以省略

前面的範例把 `return 0;` 明確寫出來，方便認識「回傳狀態」這件事。不過，**當 `main` 自然執行到最後的右大括號時，即使沒有寫 `return 0;`，也會回傳 `0`，表示正常完成。**

因此，下面這支程式也是完整、合法的 C++ 程式：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
}
```

這個範例和前面有寫 `return 0;` 的版本，輸出結果相同。

請注意，省略的是 `main` 結尾的 `return 0;`，不是 `int main()`，也不是大括號。這是 `main` 的特殊規則，不要直接套用到其他需要回傳值的函式。
