## 一、看起來很像，也可能是不同的字元

寫程式時，文字、大小寫和標點符號都是語法的一部分。有些符號看起來很接近，電腦卻會把它們視為不同的字元。

先比較下面兩個敘述：

```cpp
// 正確示意：語法使用半形符號
cout << "Hello" << endl;
```

```text
錯誤示意：外面的雙引號與結尾分號換成了其他字元
cout << ＂Hello＂ << endl；
```

第二個範例裡的 `＂`、`；` 與程式語法使用的 `"`、`;` 不同。即使文字內容沒有變，程式仍可能無法通過編譯。

**輸入 C++ 語法時，請使用英文輸入狀態與半形符號。** 切換方式依輸入法設定而定；不要只看鍵盤上的按鍵，也要檢查畫面上實際輸入了哪個字元。

### 半形、全形與彎引號

| 程式語法使用的半形符號 | 常見的相似字元 | 留意的地方 |
| --- | --- | --- |
| `;` | `；` | 前者是半形分號，後者是全形分號。 |
| `"` | `＂`、`“`、`”` | 全形雙引號、左右彎引號，都不能取代字串外面的半形雙引號。 |
| `(`、`)` | `（`、`）` | 語法中的小括號要用半形。 |
| `{`、`}` | `｛`、`｝` | 主函式的大括號也要用半形。 |
| `<`、`>` | `＜`、`＞` | `#include` 與 `cout` 使用的角括號要辨認清楚。 |
| `/`、`\` | `／`、`＼` | 斜線與反斜線方向不同，也都需要半形。 |

從文書文件複製程式時，也要留意雙引號是否被自動改成彎引號。

這不代表整份程式都不能有中文。例如下方字串中的中文與全形驚嘆號，是我們想輸出的內容，可以保留：

```cpp
cout << "你好，世界！" << endl;
```

重點是分清楚：**哪些符號負責組成語法，哪些字元是字串或註解的內容。**

## 二、特殊符號怎麼按？

下表以常見的**美式鍵盤配置、英文輸入狀態**為例。若你的鍵盤配置不同，請以實際配置為準。

`Shift + 按鍵` 的意思是：**按住 `Shift`，再按另一個按鍵**，輸入後放開。

| 要輸入的符號 | 常見按法 | 用在什麼地方 |
| --- | --- | --- |
| `#` | `Shift` + `3` | `#include` 開頭。 |
| `"` | `Shift` + 單引號鍵 `'` | 字串的開始與結束。 |
| `;` | 直接按分號鍵 `;` | 敘述的結尾。 |
| `(`、`)` | `Shift` + `9`、`Shift` + `0` | `main()` 的小括號。 |
| `{`、`}` | `Shift` + `[`、`Shift` + `]` | 主函式的範圍。 |
| `<`、`>` | `Shift` + 逗號鍵 `,`、`Shift` + 句點鍵 `.` | `<iostream>` 與輸出運算子。 |
| `/` | 直接按斜線鍵 `/` | `//` 或 `/* ... */` 註解。 |
| `\` | 直接按反斜線鍵 `\`，位置依鍵盤而異 | 字串中的 `\n`。 |
| `*` | `Shift` + `8` | `/* ... */` 區塊註解。 |

`<<` 不是方向鍵，也不是單獨一個特殊按鍵。請連續輸入兩次 `<`。同樣地，`//` 就是連續輸入兩次 `/`。

### 動手練習：你輸入的是哪一種符號？

選擇一個目標，再親自用鍵盤輸入。也可以先帶入全形範例，觀察看起來相似的符號為什麼不相同。這個練習只比較指定的符號，不會編譯整份 C++ 程式。

## 三、分號是敘述的結尾，不是每行的結尾

這些敘述需要分號：

```cpp
using namespace std;
cout << "Hello" << endl;
return 0;
```

但是 `#include <iostream>` 不加分號，範例中的 `int main() {` 和結束用的 `}` 也不需要另外加分號。

一個敘述可以分成好幾行，例如下面仍然是一個輸出敘述，最後只有一個分號：

```cpp
cout << "Hello, "
     << "C++!"
     << endl;
```

反過來說，程式碼換行不代表輸出換行。想讓輸出換到下一行，仍要使用 `endl` 等換行方式。

## 四、大小寫與縮排

C++ 會區分大小寫。這些名稱請保持正確：`main`、`cout`、`std`、`endl`。

例如 `Cout` 和 `cout` 是不同的名稱，不能任意替換；`endl` 最後一個字元是小寫英文字母 `l`，不是數字 `1`。

縮排則是為了讓程式更容易閱讀。建議把 `main` 大括號裡的敘述向右縮排，並讓同一層的敘述對齊。不要用全形空格進行程式縮排。

字串內的空格是另一回事：`"A B"` 中間的空格屬於輸出內容，會出現在結果裡。

## 五、註解是寫給人看的說明

### 單行註解：`//`

從 `//` 開始到該行結尾的內容是註解，可以放在敘述前面或後面：

```cpp
// 下一行輸出歡迎文字
cout << "歡迎學習 C++！" << endl; // 這裡也可以補充說明
```

### 區塊註解：`/* ... */`

區塊註解從 `/*` 開始，到 `*/` 結束，內容可以跨行。初學時不要把另一組區塊註解包在裡面。

```cpp
#include <iostream>
using namespace std;

int main() {
    /*
       這一段是說明文字，
       可以分成好幾行。
    */
    cout << "歡迎學習 C++！" << endl;
}
```

註解不會成為執行指令，也不會自動成為輸出內容。想讓文字出現在結果中，要把它交給 `cout`。

## 六、輸入完成後，自己檢查一次

- [ ] 作為語法的分號、括號、引號與角括號，都使用半形。
- [ ] `<<` 的方向正確，而且確實有兩個 `<`。
- [ ] `main`、`cout`、`std`、`endl` 的大小寫正確。
- [ ] 字串左右使用半形雙引號，沒有混入全形雙引號或彎引號。
- [ ] 需要分號的敘述已加上分號，大括號也有配對。
- [ ] 註解符號的方向與順序正確，區塊註解已結束。

剛開始寫程式時，先把符號輸入正確，比打字速度更重要。遇到錯誤，可以從最近修改的那一行開始，逐個字元檢查。
