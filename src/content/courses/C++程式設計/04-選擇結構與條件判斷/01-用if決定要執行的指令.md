## 一、讓程式依情況做事

「分數至少 60 分，就輸出 Pass」可以拆成條件與行動。`if` 負責檢查條件，`{ }` 裡寫條件成立時要做的事。

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 75;
    if (score >= 60) {
        cout << "Pass" << endl;
    }
    cout << "Done" << endl;
    return 0;
}
```

輸出結果：

```text
Pass
Done
```

`score >= 60` 會得到 `true` 或 `false`，決定這次是否進入 if 的大括號區塊：

- 結果是 `true`：進入大括號，執行裡面的 `cout << "Pass" << endl;`，輸出 Pass。做完後離開區塊，再往下執行。
- 結果是 `false`：**直接跳過整個大括號區塊，裡面的指令都不執行**，所以這次不會輸出 Pass；接著從右大括號 `}` 後面的指令繼續執行。

`cout << "Done" << endl;` 寫在 if 的大括號外面，因此兩種情況都會執行它：75 分會依序輸出 Pass、Done；59 分則只會輸出 Done。

## 二、讀懂 if 的三個部分

~~~cpp
if (條件) {
    條件成立時的指令;
}
~~~

`if` 是關鍵字，條件放在半形小括號裡，行動放在半形大括號裡。上面這段是語法示意，實際寫程式時要把中文替換成條件與指令。

大括號可以包住多行。例如及格時同時輸出兩句話，就把兩個 `cout` 都放進同一組大括號。先養成使用大括號與縮排的習慣，會更容易看出哪些指令屬於這個條件。

## 三、特別留意等號與分號

**比較是否相等使用 `==`，不要把 `if (a == 2)` 寫成 `if (a = 2)`。** 後者會先把 `a` 改成 `2`；非零值被視為 `true`，所以還會進入區塊，原本想做的比較就變了。

**`if (條件)` 後面直接接大括號，不要多加分號。** `if (score >= 60);` 的分號會讓 if 的本體成為一個空敘述；後面的大括號區塊就會獨立執行。大括號裡的 `cout` 敘述則照常以分號結尾。
