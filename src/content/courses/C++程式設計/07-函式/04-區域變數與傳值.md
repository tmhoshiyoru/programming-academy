## 一、同名變數也可以各自獨立

函式裡建立的變數，通常只在它所屬的區塊內使用，稱為**區域變數**。main 的 score 和 change 的參數 score 雖然同名，卻是兩個不同的變數。

```cpp
#include <iostream>
using namespace std;

void change(int score) {
    score += 10;
    cout << score << endl;
}

int main() {
    int score = 80;
    change(score);
    cout << score << endl;
    return 0;
}
```

輸出結果：

```text
90
80
```

呼叫 `change(score)` 時，main 把目前的值交給參數。change 把自己的 score 增加 10，main 的 score 仍然保留原值。

## 二、傳值：交出一份資料

這種參數寫法稱為**傳值**。可以想成把數字抄到另一張紙上：修改收到的那張紙，原本的紙仍保留原來的數字。

如果希望 main 接收新分數，可以讓函式回傳結果，再由 main 指定給自己的 score：

~~~cpp
int addTen(int score) {
    return score + 10;
}

// main 內使用
score = addTen(score);
~~~

這時 main 的 score 會改變，是因為最後這個指定敘述把回傳結果存回去。其他參數傳遞方式之後再介紹。

## 三、區塊也有使用範圍

在 `for (int i = 0; ... )` 裡建立的 i，只在該迴圈的範圍內使用。先前的互動範例在離開迴圈後移除 i，就是配合這個規則。

需要在迴圈結束後繼續使用的答案，例如 sum、position，可以在迴圈前建立，讓後面的指令也能取得它們。
