## 一、替一段工作取名字

前面把指令寫在 main 裡。當一段工作有清楚的用途，就可以把它整理成另一個**函式**，取一個名字，需要時再呼叫它。

例如 square 專門計算一個整數的平方。

```cpp
#include <iostream>
using namespace std;

int square(int number) {
    return number * number;
}

int main() {
    int answer = square(4);
    cout << answer << endl;
    return 0;
}
```

輸出結果：

```text
16
```

程式從 main 開始執行。遇到 `square(4)`，就先進入 square 計算，得到結果後回到原本的呼叫位置，再繼續往下。

## 二、讀懂函式的外觀

~~~cpp
int square(int number) {
    return number * number;
}
~~~

- 最前面的 `int`：函式會交回一個整數，稱為**回傳型態**。
- `square`：函式名稱，描述這段工作的用途。
- `int number`：接收資料的參數；這裡接收一個整數。
- `{ }`：執行這段工作所需的指令。
- `return`：把結果交回呼叫處，並結束這次函式執行。

## 三、回傳結果和輸出到畫面不同

square 中的 return 把數值交回程式，畫面還沒有顯示任何內容。main 裡的 cout 才把 answer 輸出到畫面。

同一個回傳值也可以拿去做其他運算，例如 `int total = square(3) + 1;`，total 會是 10。
