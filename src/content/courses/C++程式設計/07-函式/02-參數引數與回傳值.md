## 一、呼叫時把資料交給函式

函式可以接收一個以上的資料。本例接收兩個整數，回傳「第一個減去第二個」的結果。

```cpp
#include <iostream>
using namespace std;

int difference(int a, int b) {
    return a - b;
}

int main() {
    int x = 10;
    int y = 3;
    int result = difference(x, y);
    cout << result << endl;
    return 0;
}
```

輸出結果：

```text
7
```

函式定義中的 a、b 叫作**參數**，是函式內接收資料的變數。呼叫時提供的 x、y 叫作**引數**，也就是這次實際交出去的資料。

可以先記成：參數是函式準備好的接收位置，引數是這次放進去的內容。

## 二、依照位置配對

`difference(x, y)` 把 x 的值交給 a、y 的值交給 b。名字可以不同，配對依據是位置。

`difference(10, 3)` 得到 7；`difference(3, 10)` 得到 -7。呼叫時確認順序、個數和接收的型態，就能清楚知道函式拿到了什麼。

引數也可以是運算式，例如 `difference(x + 2, y)`，會先取得 x + 2 的值，再交給第一個參數。

## 三、每一條回傳路徑都要有答案

~~~cpp
int larger(int a, int b) {
    if (a >= b) {
        return a;
    }
    else {
        return b;
    }
}
~~~

這個函式不論走哪條路，都會回傳一個整數。執行到 return 就結束本次呼叫。

第一章提過，main 走到最後時可以省略 `return 0;`。這是 main 的特別規則；自己定義、需要回傳數值的函式，要讓每一條可能執行完的路徑都交回結果。
