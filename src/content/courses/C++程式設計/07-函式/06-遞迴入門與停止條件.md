## 一、函式也能呼叫自己

函式在工作過程中呼叫自己，叫作**遞迴**。可以先把一個問題交給「處理較小問題的自己」，等答案回來，再完成目前這一層。

以階乘為例，`4!` 是 4 × 3 × 2 × 1，也可以寫成「4 乘上 3!」。最小情況約定為 `0! = 1`。

```cpp
#include <iostream>
using namespace std;

int factorial(int n) {
    if (n == 0) {
        return 1;
    }
    return n * factorial(n - 1);
}

int main() {
    int answer = factorial(4);
    cout << answer << endl;
    return 0;
}
```

輸出結果：

```text
24
```

這篇只練習 0 到 6 的非負整數，讓呼叫層數與計算結果都容易觀察。

## 二、停止條件與較小的問題

遞迴函式有兩個重點：

1. **停止條件**：n 為 0 時，直接回傳 1。
2. **往停止條件前進**：其他情況呼叫 factorial(n - 1)，讓 n 每次減少 1。

這個版本以非負整數為使用範圍。負數持續減 1 會離 0 越來越遠，因此在自己的輸入程式中，可以先檢查資料是否位於規劃的範圍。

## 三、先往下呼叫，再逐層回傳

計算 factorial(3) 時，呼叫順序是 3 → 2 → 1 → 0。到 0 回傳 1 後，依序算出：

- factorial(1)：1 × 1 = 1。
- factorial(2)：2 × 1 = 2。
- factorial(3)：3 × 2 = 6。

每次呼叫都有自己的參數 n。外層等待內層的結果，因此回到某一層時，仍能用該層原本的 n 繼續計算。

## 四、和迴圈版本比較

~~~cpp
int result = 1;
for (int i = 1; i <= 4; i++) {
    result *= i;
}
cout << result << endl;
~~~

這個迴圈也會得到 24。階乘用兩種寫法都能完成；本節先透過它看懂遞迴的呼叫與回傳。呼叫層數過多會消耗額外資源，後續解題時再依問題選擇合適方式。
