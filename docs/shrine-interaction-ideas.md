# 網海神社互動地標構想

已確認的四個互動方向：

- **拜殿｜參拜節奏**：先選擇祈願內容，再依時機完成一般參拜作法「二拜、二拍手、默禱、一拜」。
- **手水舍｜訊號操作**：控制水波傳遞訊息，面對風、石頭和波紋干擾；可帶到訊號、雜訊與通訊。
- **受付所｜即時調度**：安排參拜者、祭典隊伍與物資通行，處理入口壅塞和時間限制；可帶到排程與資源分配。
- **鳥居｜地圖探索**：扮演電波穿越森林、山洞等地形，尋找中繼點抵達目的地；可帶到無線訊號、衰減與遮蔽。

目前製作：拜殿「參拜節奏」遊戲。玩家可選擇資訊科技相關心願，依視覺節拍練習參拜禮儀；拍手、鈴聲與鳥鳴由瀏覽器即時合成，不需外部素材。
